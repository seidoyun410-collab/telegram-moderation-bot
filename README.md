Telegram Moderation Bot
Backend Pet Project (Python)
О проекте

Разработал Telegram-бота для приёма пользовательских объявлений с системой модерации и реализацией платных тарифов размещения.

Проект создан для практики backend-разработки, асинхронной логики и серверного развёртывания.


Реализовано:

· Приём объявлений от пользователей

· Многошаговый сценарий через FSM

· Передача заявок в отдельную модерационную группу

· Inline-кнопки для одобрения / отклонения

· Реализация простых платных тарифов

· Передача выбранного тарифа модератору

· Разделение логики по модулям (handlers, keyboards)

· Асинхронная обработка событий (async/await)

· Развёртывание на VPS (Arch Linux)

· Автозапуск через systemd


Используемые технологии:

· Python 3.10+

· aiogram 3.x

· Async / await

· FSM

· Git

· Linux


Чему научился в процессе:


· Работе с асинхронным Python

· Организации структуры backend-проекта
